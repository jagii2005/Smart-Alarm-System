# Smart Alarm System

## Project Description
The Smart Alarm System is an IoT-based security project developed using ESP32. It monitors security events using sensors and activates an alarm whenever an intrusion or abnormal condition is detected. The project is designed and simulated using the Wokwi platform.

## Features
- ESP32-based smart security system
- Real-time sensor monitoring
- Automatic alarm activation
- IoT simulation using Wokwi
- Easy to modify and expand

## Components Used
- ESP32
- Ultrasonic Sensor
- Buzzer
- LED
- Jumper Wires

## Software Used
- Arduino IDE
- Wokwi Simulator

## Project Files
- `diagram.json` – Circuit design
- `sketch.ino` – Arduino source code
- `libraries.txt` – Required libraries
